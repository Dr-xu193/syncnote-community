# 当前边界与已知限制

- 社区版提供客户端和源码，需要使用者配置自己的服务，不是免配置托管产品。
- Firebase / Google 服务的网络可用性取决于地区和网络。项目未提供国内替代同步后端。
- Windows 与 Android Firestore 使用内存缓存。退出前尚未同步完成的离线修改没有磁盘缓存兜底，请等待同步完成再退出。
- WebDAV 凭据按设备配置；多人共用存储账号不具备 Firebase UID 一样的文件隔离。
- 新闻正文提取、文献匹配、公开股票接口有来源与覆盖限制，AI 结论必须结合引用核对。
- 股票研究为个人验证与虚拟模拟。公开接口并非商业授权行情，股票数据可能延迟、缺失或停止服务。
- 当前股票模拟尚未完整处理分红、红利税与全部公司行为，含相关事件的收益可能失真；日记中的文字买卖条件也不等于已经实现条件单。请勿用模拟结果替代真实账户核算。
- 自动模拟决策只在 Windows 应用运行时按日检查；关机期间不会补造历史成交。Python 内核需单独安装，Android 只读实验结果。
- Android 后台提醒依赖系统授权、网络和厂商后台管理，无法保证所有设备全天常驻。
- 当前安装包不包含自动更新功能，更新请到官方 Releases 页面下载。
