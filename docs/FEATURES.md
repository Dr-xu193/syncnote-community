# 功能与使用场景手册

本页描述当前源码已有的主要能力。外部接口可用性、解析质量、AI 回答质量和系统后台行为不能由功能列表保证；已知边界另见 KNOWN_LIMITATIONS.md。

## 个人记录与行动

### 备忘录

适合快速收集临时想法、链接、图片和语音。支持置顶和媒体附件；列表用有限内容预览展示长记录。AI 入口用于将零散表述整理为更清楚的内容。

### 任务

每个任务可以包含名称、描述、状态、优先级、截止时间和多个提醒。重复规则、子任务、标签与归档帮助处理周期性事务和复杂目标。列表提供当前、今日、逾期、今日完成及归档等筛选，也支持 AI 辅助整理顺序。

Windows 与 Android 读取同一用户的云端任务。Android 的本机提醒、重建与后台补偿能力依赖通知、精确闹钟和系统后台权限，不能把“允许后台”视为所有厂商设备的准时保证。

### Markdown 笔记与知识关系

笔记支持编辑 / 预览、代码块高亮、图片和语音等输入。通过分类、标签、搜索和 Wiki 风格关联建立结构，关系图谱展示笔记之间的连接。历史版本和冲突处理提供回溯、保留双方或手动合并等操作，不能替代独立备份。

### 日记

围绕日期、内容和心情保存记录，可附媒体资料。AI 功能可以基于所选资料辅助回顾；晨间简报和晚间复盘提供可关闭的自动入口。AI 不替用户定义真实情绪、诊断或人生结论。

## 统一 AI 工作流

### 选中文字就地处理

已集成的输入框和可选中文本提供 SyncNote AI 菜单，支持智能润色、结构化整理、中英互译与扩写。处理完成后可复制结果，支持编辑回填的入口还可以替换原选区。

### 对话、资料与长期记忆

智能中心支持多个云端会话。用户可以指定会话资料范围、添加只服务于该会话的参考资料，并管理长期记忆。系统结合相关资料和历史上下文回答问题，并展示来源和用量信息。

它适合围绕“我最近在关注什么”“这些资料有哪些共同点”“把相关任务和笔记一起整理”等开放问题继续讨论。检索不等于整个数据库都会发送；历史上下文也有预算，不承诺无限保留在单次模型请求中。

### 多媒体内容整理

图片文字提取、语音转写、网页正文及可用视频字幕可以成为整理输入。链接提炼提供大纲、深度分析和行动指南等方向。网页限制、视频没有字幕、接口失败或音频质量较差时，取得的信息可能不完整。

## 文献：检索、阅读与沉淀

1. **描述问题**：输入研究问题或关键词，也可保存常用研究方向。
2. **发现候选**：从 OpenAlex、Semantic Scholar、Crossref、arXiv、Europe PMC 等来源检索，组织研究主题、核心概念和拓展阅读。
3. **判断相关性**：查看标题、摘要、年份、来源、引用信息及推荐理由；排序是辅助信号，不能代替研究者筛选。
4. **继续深读**：核心解读明确依据摘要；取得开放 PDF 后再进行全文提取与深度解读。
5. **建立阅读库**：收藏、阅读状态、标签和备注，保存深度解读和摘录。
6. **沿关系探索**：查看参考、后续引用和相似研究，选择值得继续阅读的文献。
7. **沉淀到知识库**：生成 Markdown 文献研究笔记，将开放 PDF 保存到自己的云文件。

系统只处理合法可取得的文献与开放 PDF，不包含绕过付费墙的服务。检索和相关性分析仍可能遗漏重要研究，写作前应核对原文、数据与引用。

## 新闻与思维训练

新闻区把多来源内容放入多个主题栏目，保存当日阅读快照并允许主动刷新。文章保留来源入口，正文提取失败或不完整时应回到来源核对。

知识卡片当前包含 168 条条目，逻辑谜题当前包含 100 个条目。谜题提供分阶段输入、评分和反馈及进度记录。内容属于可持续修订的学习素材，AI 评判可能出错，欢迎提交具体反例和改进建议。

## 股票研究与可解释的虚拟实验

研究实验室包括市场雷达、股票搜索、K 线、确定性指标、筛选器、关注池、研究记录、组合计划与模拟盘。公开源主要服务个人研究，不代表完整、连续、商业授权的行情覆盖。

单独的 AI 虚拟实验以 1000 元初始虚拟资金运行 30 个自然日。AI 可以研究、选择标的、形成目标仓位或持币；工具只读，模型不会直接操作券商。Python 执行内核记录现金、整手、费用、模拟成交和拒单，Flutter 负责界面、资料获取与研究交互。

逐日 JSON 日记保存最终研究说明、被放弃的候选、不确定性、预期、目标组合、执行事件和账户状态。周报和期末报告可以回到对应日记。当前原始工具响应留存与公司行为处理仍不完整，不能把“保存了日记”理解为已实现全部证据可回放或专业级实盘核算。

Windows 应用运行时按日检查；手机负责同步查看。没有运行的时间不会被补造成已经发生的交易。模型费用、数据缺失和执行限制应与收益一起观察。

## 云文件与长期数据管理

任何类型文件都可以作为云文件上传，是否能预览取决于格式支持。PDF、文本、图片和支持的 Office 文档可以在应用内查看内容；Office 预览不承诺与桌面原应用逐像素一致。

Firebase 保存结构化记录与轻量索引，WebDAV 保存较大的文件、附件和归档正文。分页读取、归档、冷归档、容量参考与按需恢复共同控制常用工作集大小。完整 ZIP 用于数据迁移与备份恢复，应用另有回收站及笔记历史版本。

云文件预览与其他附件播放、分享、导出流程的本地行为并不完全相同，具体数据去向见 PRIVACY.md。使用者应保管自己的服务凭据和备份，定期确认恢复流程可用。
